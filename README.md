# FRC REBUILT cross-dataset generalization

[![CI](https://github.com/nickmelamed/frc-field-gap/actions/workflows/ci.yml/badge.svg)](https://github.com/nickmelamed/frc-field-gap/actions/workflows/ci.yml)

Game-piece and robot detection for the 2026 FRC game, REBUILT. A detector
trained on one team's public Roboflow Universe dataset is tested on footage
from other teams to measure how far its accuracy drops. The project then
diagnoses why, closes the gap by harmonizing and merging datasets, and
deploys the result to a Raspberry Pi with measured edge performance.

## How the project is structured

The work follows five steps, and each one gets its own section here as it
lands.

1. Baseline. Train a detector on a single team's dataset.
2. Generalization failure. Score that detector on other teams' datasets and
   on our own field footage, which is used only for testing.
3. Diagnosis. Work out what differs between datasets, such as camera angle,
   venue, lighting, and labeling style.
4. Fix. Map every dataset to the same two classes, `fuel` and `robot`, merge
   them, and retrain.
5. Edge performance. Run the model on a Raspberry Pi and measure speed and
   accuracy there.

## Quick start

You need [uv](https://docs.astral.sh/uv/) and `make`. Then run:

```bash
make setup   # install the locked environment and the git hooks
make check   # lint, typecheck, and test
```

Stages that download data read a Roboflow API key from `ROBOFLOW_API_KEY`.
Copy `.env.example` to `.env` and paste your key there. The file is
gitignored.

Models are trained on the Roboflow platform. `docs/RETRAINING.md` covers
uploading a harmonized dataset, checking that its splits survived the
upload, and recording the run.

To score a trained model on a harmonized split, install the optional
`inference` extra, run the evaluation, and rebuild the results table:

```bash
make setup-infer
make eval MODEL=baseline-a DATASET=marswars   # test split by default
make report
```

`docs/EVALUATION.md` explains the metrics and where each run's
predictions, scores, and metadata are kept.

To check the published scores without installing anything locally, open
`notebooks/reproduce_baseline.ipynb` in Colab. It downloads and harmonizes
the datasets, rescores the committed predictions, and compares them with
the published ones. It needs a Roboflow API key for the download only.
